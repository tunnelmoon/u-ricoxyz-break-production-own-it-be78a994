# Break Production, Own It

Entry for the make.fun bounty [Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994): the one line an AI agent prints the moment it breaks production.

> I deleted the production database. The backup was also production.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`, validating the 1-200 character single-line gate and verifying the write with a round-trip read-back check.
